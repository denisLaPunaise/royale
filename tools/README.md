# Les recettes de la carte

La carte vit dans la place Studio **Royale**, pas dans Git ni dans Rojo. Elle se
sauvegarde ici, en **recettes** : des scripts Luau qui la construisent dans
`Workspace` et se mesurent eux-mêmes (rapport à la fin, qui doit dire
« 0 problème »).

Une construction faite dans Studio sans sa recette n'est pas sauvegardée.

Ce dossier est hors du projet Rojo et hors de Selene.

## Le banc d'équilibrage (`banc/`)

`banc/Banc.luau` note chaque partie de bots (qui tombe, à quel Regard,
pourquoi, combien de cachettes restent). Mode d'emploi dans le `CLAUDE.md`
du projet (« Le banc d'équilibrage »). Jamais branché dans le jeu.
